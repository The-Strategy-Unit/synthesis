# Virtual Event Backstage Interface

The 'backstage' is a dedicated backend space within the virtual event platform, distinct from the public attendee view. It serves as a preparation area for hosts, speakers, and support staff, allowing technical checks and coordination to occur privately. Speakers join this area automatically via direct invite links, which also serve as a backup access method if they encounter issues joining the main session. Within the backstage, speakers can view the attendee chat, panel chat, and Q&A sections, while remaining invisible to the live audience. This separation ensures that preparatory activities, host communications, and technical troubleshooting do not disrupt the attendee experience.

The interface is designed to reduce the cognitive load on presenters. It provides a space for speakers to 'hang out' and calm down before going live, verifying that their equipment is ready. Upon logging in, speakers are offered a 'take a tour' button to guide them through the interface functions, ensuring they can navigate the backstage and live features effectively. The backstage environment mirrors many functionalities of the host view but is tailored for the presenter's needs, allowing them to see their own camera feed and shared screen as they appear to attendees.
