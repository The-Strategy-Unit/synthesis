# Vaccine Coding Error Propagation Across Data Systems

Vaccination events are coded into General Practice (GP) IT systems, and multiple data sources—including Inform, FTP, and CHIS—rely on these codes to determine vaccination status. If a vaccination event is not coded correctly in the GP IT system, the child appears unvaccinated across all downstream data sources, regardless of whether they actually received the vaccine. This error propagation can create significant anomalies, such as a practice appearing to have 85% of its primary-age children unvaccinated. Such outliers are likely indicative of coding issues at the practice level rather than true vaccination gaps, highlighting the critical importance of accurate coding for the integrity of all derived datasets.
