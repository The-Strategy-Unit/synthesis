# Interactive equity reporting with Quarto and R

To make data reports more engaging and accessible, interactive reports can be created using Quarto through R, utilizing packages such as Plotly and Leaflet for interactive plots and maps. Publishing these reports as HTML on GitHub Pages allows for easy sharing, linking to specific sections, and wider reach. This approach helps stakeholders who may find static numbers less engaging to identify areas of interest within the data. Ensuring reproducibility in health analytics involves writing all code and functions in R to consistently calculate metrics such as the equity index and to maintain consistent plot aesthetics. Using custom CSS to apply a familiar NHS format to reports can build trust and familiarity among users. Reproducible workflows allow for iteration in future versions of reports and facilitate the integration of predictive and forecasting analytics, as well as analysis of flow between population segments.
