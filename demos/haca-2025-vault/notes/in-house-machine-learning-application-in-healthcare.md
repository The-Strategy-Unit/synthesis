# In-house machine learning application in healthcare

The study highlighted the benefits of applying machine learning methods in-house rather than relying on external companies. External providers often present findings as a 'black box,' making it difficult to appraise the outputs or the methods used. By conducting the analysis internally using both R and Python, the team maintained transparency and control over the modelling process. This approach allowed for a better understanding of which model worked best and why, although in this instance, both approaches yielded similar results.

The in-house application also facilitated a more nuanced interpretation of the data, even if it did not align with the preferred BI dashboard style of some senior managers. The experience underscored the value of having internal expertise to navigate the complexities of healthcare data and modelling, ensuring that insights are both technically sound and contextually relevant to organisational decision-making.
