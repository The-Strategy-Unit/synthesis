# Waste Normalization in Data Teams

Waste normalization refers to a common organizational pattern in data teams where multiple groups respond separately to similar requests, leading to redundant work and fragmented insights. This phenomenon manifests as multiple extracts of the same data, slight variations in logic, parallel dashboards, and side-of-desk files that never become reusable assets. The issue arises when teams such as data development, engineering, visualization, and planning operate in isolation, processing the same 'logs' of data in different ways without awareness of each other's work.

This lack of disciplined, repeatable methods for turning data into trusted insight results in significant inefficiency. The problem has been highlighted in contexts such as the Goldacre Review, which identified the need for more structured approaches to data management. Recognizing and addressing this normalized waste is considered a precursor to implementing more structured operating models, such as the Woodyard Model, which aim to consolidate efforts and create single sources of truth.
