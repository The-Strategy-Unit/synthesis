# RAP Code Review Buddy Network

The RAP Code Review Buddy Network is a program launched in January by the NHS Strategy Unit's data science team, emerging from code-sharing practices observed in the RAP drop-in sessions. The network pairs analysts randomly every three months to engage in 'code walks' rather than formal code reviews. Participants meet online to discuss their code, ask critical questions, and provide supportive feedback.

The program is open to anyone who has written code for their job in the last three months, regardless of the programming language (R, Python, SQL, etc.) or the sophistication of their pipeline. It aims to improve code quality through peer feedback, enhance discoverability of work, and foster a supportive community. Guidance on how sessions work and what constitutes good code review is available online, including references to external resources like a blog post by Jack Kennedy on code review for statisticians. The program is currently organized by a small team, and co-organizers are sought.
