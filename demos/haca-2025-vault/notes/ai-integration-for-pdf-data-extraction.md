# AI integration for PDF data extraction

The trust integrated AI tools to extract information from PDFs for input into the sustainability dashboard. This process is described as a 'showy' part of the workflow but is noted to be completely reliant on a very consistent format in the source documents. The use of AI is characterized as sparing but effective for ripping information off PDFs, addressing the challenge of manual data entry from inconsistent supplier documents.
