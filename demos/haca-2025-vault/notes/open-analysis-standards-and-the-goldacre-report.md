# Open Analysis Standards and the Goldacre Report

Open analysis standards require analysts to proactively share their work and document it in a way that allows any other analyst in any Integrated Care Board (ICB) or provider to use it. This approach contrasts with creating proprietary intellectual property (IP) that is locked down or sold. Referencing the Goldacre Report, the emphasis is on adopting standards that promote transparency and reusability in analytical work, ensuring that insights and methods are accessible to the broader healthcare community. The core principle is that analysts should document their work so that it can be reused, opposing the creation of proprietary IP that is protected or sold. This fosters a culture of collaboration and shared learning across the healthcare system.
