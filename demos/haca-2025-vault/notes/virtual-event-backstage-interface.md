# Virtual Event Backstage Interface

The 'backstage' is a dedicated backend space within the virtual event platform, distinct from the public attendee view. It serves as a preparation area for hosts, speakers, and support staff, allowing technical checks and coordination to occur privately. Speakers join this area automatically via direct invite links, which also serve as a backup access method if they encounter issues joining the main session. Within the backstage, speakers can view the attendee chat, panel chat, and Q&A sections, while remaining invisible to the live audience. This separation ensures that preparatory activities, host communications, and technical troubleshooting do not disrupt the attendee experience.

The interface is designed to reduce the cognitive load on presenters. It provides a space for speakers to 'hang out' and calm down before going live, verifying that their equipment is ready. Upon logging in, speakers are offered a 'take a tour' button to guide them through the interface functions, ensuring they can navigate the backstage and live features effectively. The backstage environment mirrors many functionalities of the host view but is tailored for the presenter's needs, allowing them to see their own camera feed and shared screen as they appear to attendees.

The virtual conference is hosted on the Hubilo platform, accessible via a unique invitation link, preferably using the Chrome browser. First-time users must log in with a one-time password and set up a profile including a picture, job title, and organisation. The platform interface includes a 'Reception' landing page, a 'Program' section for browsing and scheduling sessions, and a 'People' section for networking via direct chat or scheduled meetings.
<!-- synthesis-claim:3e767760010e8518f1327843b9a281548b349b9105e696daa282966089349ec5,c694f5302fdd7d6358cd12f1dcd947fd2f6dea83d2185f30fbbb2653d4850f90 -->

A 'Poster Booth' section allows presenters to upload poster descriptions, contact details, and downloadable materials. Presenters can optionally link an unlisted YouTube video to their booth banner. Attendees can engage with posters using an 'I'm interested' button, which transmits their contact information to the presenter and allows for scheduling follow-up meetings. The 'Lounge' area facilitates networking sessions similar to face-to-face interactions.
<!-- synthesis-claim:3e767760010e8518f1327843b9a281548b349b9105e696daa282966089349ec5,c694f5302fdd7d6358cd12f1dcd947fd2f6dea83d2185f30fbbb2653d4850f90 -->

Technical support is provided by the 'hack team', who can send direct invite links to resolve connectivity issues. The platform includes a 'Backstage' area for speakers to test audio and video equipment before going live. Hosts manage the stream, adding speakers to the screen and integrating slide decks via screen sharing. A panel chat feature allows private communication between hosts and speakers for technical assistance.
