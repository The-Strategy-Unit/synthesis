# SROI Implementation Process

Implementing an SROI model involves several distinct steps. First, the scope is established by defining the boundaries of the analysis, clarifying its purpose, available resources, and measurement priorities to ensure realism. Second, outcomes are mapped using an impact map, which illustrates how resources (inputs) are used to deliver activities (outputs) that lead to stakeholder outcomes. This relationship is known as a theory of change or logic model.
<!-- synthesis-claim:651e9761d6dda19cef3e89a2503ed23462f6b9d8fc1b0395268f1a2a855a3b82 -->

Third, evidence is gathered and value is assigned by defining indicators, collecting data, and assessing impact. This includes determining the duration of outcomes, assigning financial proxies using established costs and benchmarks, and establishing impact. Crucially, this step requires avoiding overclaiming by estimating dead weight (what would happen without the project), displacement (whether it replaces other outcomes), attribution (who else contributed), and drop-off (whether effects decline over time). Only after considering these factors can the true effect of the intervention be measured. The impact map should be treated as a living document with regular revisions to improve accuracy.
