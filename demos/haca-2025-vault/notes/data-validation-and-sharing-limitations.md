# Data Validation and Sharing Limitations

The data feeding the dashboard is explicitly described as unvalidated, a warning that is displayed across the entire dashboard. Despite this, the data is shared widely because it utilizes 'sitrep' (situation report) style data which offers granularity without containing background information about individual patients. The engagement with provider colleagues and the nature of the sitrep star reporting allowed for the sharing of content and delivery outputs. The system is designed to be scalable, with the fundamental aspect being the ground-up building of data infrastructure, utilizing services such as 'Making Data Count' in the background.
