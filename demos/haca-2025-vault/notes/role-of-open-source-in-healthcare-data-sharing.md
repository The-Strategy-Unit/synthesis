# Role of open source in healthcare data sharing

The use of open-source communities and reproducible pipelines is a significant enabler for international collaboration and the wider adoption of emergency department (ED) capacity models. Specifically, the R and Python ecosystems facilitate the sharing of methods for preparing real-time data for predictions, a process described as tricky and non-trivial. By sharing these technical workflows, organizations can lower barriers to entry for other teams looking to implement similar solutions, allowing institutions to build upon existing work rather than developing solutions from scratch.

There is strong advocacy for mainstreaming open-source and open-sharing cultures within the NHS, contrasting this with the commercial sector where competitive pressures inhibit sharing. A proposed shift in analytical practice involves moving from 'reproducibility' to 'reusability,' which entails borrowing code with pride and developing solutions collaboratively across the system. This includes the creation of a national code library of open-source public health packages to serve as a shared foundation. It is predicted that within ten years, open sharing will become standard practice, allowing analysts to find battle-tested code via simple searches and pilot solutions in weeks. Sharing work through public repositories like GitHub, blogs, or talks is recommended for building an online portfolio and improving analytical skills by forcing analysts to explain their approach to others. This openness encourages more widespread adoption and collaborative improvement within the healthcare sector.
