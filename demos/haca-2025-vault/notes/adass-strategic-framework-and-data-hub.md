# ADASS Strategic Framework and Data Hub

The ADASS strategic framework provides an analytical capability roadmap for adult social care. It includes a 'data hub' described as an accessible tool allowing users to examine local areas. The hub provides data on assurance metrics, care market profiles, finance profiles, population in need, performance metrics, and workforce profiles.

This existing infrastructure serves as a foundation for combining census information and other publicly available data to understand changes over time and place, as well as for long-term forecasting. It supports the broader goal of creating a sustainable data system that allows stakeholders to understand and improve social care support and well-being outcomes.
