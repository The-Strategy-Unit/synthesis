# Machine learning models for A&E waiting time prediction

To analyse A&E waiting times, two separate modelling approaches were conducted using Python and R to compare results and enhance current techniques. In Python, the data was split 80/20, with acuity numerically encoded and arrival hour cyclically encoded to account for temporal relationships. Linear regression served as a baseline but proved unsuitable due to data skewness. Tree-based methods, including Random Forest and Gradient Boost, were employed to improve predictability.

In R, the data was split 70/30, keeping acuity as a categorical variable. An initial Poisson model showed over-dispersion due to long waiting times, leading to the adoption of a negative binomial model for interpretable coefficients. However, tree-based methods were ultimately preferred in both environments for their accuracy. Model assessment included R-squared, residual analysis, and partial dependency plots. The Python approach was slightly quicker, but both yielded similar results, indicating a potential data ceiling for predictive accuracy given the heavy skewness of waiting time distributions.
