# Accessibility testing for Shiny applications

Testing for accessibility in Shiny applications involves several tools and methods to ensure usability for users with impairments. Lighthouse, a system available through Google, can audit pages for accessibility issues. The WAVE browser extension is another tool that identifies missing alt text and other accessibility deficits in app elements. Additionally, manual testing using screen readers and keyboard navigation is recommended to verify that users can navigate the app effectively without a mouse. These practices help identify issues such as missing labels or navigation barriers, allowing developers to improve the app's inclusivity.
