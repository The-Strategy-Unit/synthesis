# NHS Strategy Unit data science support initiatives

The NHS Strategy Unit's data science team facilitates two primary initiatives to support analysts and managers: RAP drop-in sessions and the RAP Code Review Buddy Network. These programs emerged after similar offerings previously run by NHS England ceased due to funding and changing requirements around March or April of the year prior to the presentation. Both initiatives aim to foster collaboration, knowledge sharing, and skill development within the NHS data science community, addressing common issues such as upskilling, deployment, data safety, and the isolation often experienced by analysts.

The drop-in sessions provide a regular forum for discussing technical challenges, seeking guidance, and networking, while the buddy network offers structured peer feedback through code walks. By documenting discussions on GitHub and encouraging code sharing, these initiatives contribute to a more connected and supportive environment for data professionals within the NHS. The focus is on creating a safe space for discussion, troubleshooting, and building connections, rather than providing definitive answers from facilitators.
