# North West London ICB inequality dashboard

A dashboard of inequalities developed in North West London serves as a starting point for Integrated Care Board (ICB) priorities and planning. It provides a case for change to address inequalities and allows non-NHS partners to understand decision-making processes. The dashboard enables prioritization across various demographic groups, including deprivation, ethnicity, and learning disability. While some code is available on GitHub, parts of the analysis involving secure data environments (referenced as 'Wizix') are not sharable.
