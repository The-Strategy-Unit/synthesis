# Target Deployment Model for NHS Vaccines

The Target Deployment Model (TDM) is a supply chain system developed by NHS England to automate the ordering of COVID-19 vaccines for vaccination sites. It was created to manage the logistical complexity of expanding the network from approximately 1,000 sites to 7,000 sites, replacing manual ordering processes. The model operates by combining two inputs: the current inventory position and a demand forecast. It calculates 'coverage days' (the number of days of inventory available) and automatically generates orders when specific thresholds are met. This automation significantly reduced the ordering cycle time, eliminating the need for manual creation or approval of orders.
