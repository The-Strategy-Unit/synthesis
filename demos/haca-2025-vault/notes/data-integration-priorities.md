# Data Integration Priorities

Effective data integration prioritises data standards, canonical data models, ontology mapping, and the use of tools like SNOMED CT over large software procurement decisions. Spending time and money on buying big American Electronic Patient Records (EPRs) or FTP solutions is considered less critical than ensuring robust data layers. The focus should be on linking data sets and establishing standards to enable interoperability, such as connecting GP data without integration issues and linking to the NHS app. This approach supports the convergence of data and digital systems within Integrated Care Boards (ICBs). Adhering to a canonical data model ensures that data is recorded in the same structure, facilitating linkage and benchmarking, and addressing fragmentation caused by disparate IT systems.
