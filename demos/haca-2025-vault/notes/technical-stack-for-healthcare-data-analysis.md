# Technical stack for healthcare data analysis

The analysis described utilised a combination of SQL and R. Data was held within Snowflake databases, with SQL used for extraction. R was employed for the majority of the analysis, including data visualisation and the construction of causal elements. The code for these analyses was made available on GitHub. This technical stack allows for efficient data management and advanced statistical analysis, facilitating reproducible research and collaboration among analytical teams.
