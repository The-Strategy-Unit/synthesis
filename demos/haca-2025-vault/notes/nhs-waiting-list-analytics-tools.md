# NHS waiting list analytics tools

Two primary tools have been developed to support the analysis and management of NHS waiting lists. The NHSR Waiting List package is an R software tool developed with support from the NHS R community and the Strategy Unit. Available on CRAN, it is designed for analysts to calculate statistics, make plans, simulate scenarios, and determine capacity requirements for different services. The project is active, with developers seeking collaboration to improve the package and solve specific waiting list problems.

Complementing this is a transparent, national HTML table developed to tabulate all NHS waiting lists, making publicly available data easier to interrogate. This table allows users to slice data by organization, specialty, and treatment function. It displays the current waiting list size for every provider and treatment code, calculates the required waiting list size to meet the 92% 18-week target, and determines how far off target each list is as a multiple. The tool aims to help hospital trusts quickly identify bottlenecks and pressures within their services, ensuring reproducibility and faithfulness to published data.
