# Information governance in qualitative data collection

During the project, callers asked patients about barriers to attending appointments, collecting qualitative data alongside quantitative metrics. This process did not encounter significant Information Governance (IG) hurdles, supported by a dedicated IG team. The qualitative data was not stored long-term or associated with patients in the permanent record (PASS); it existed only for the lifespan of the project. This approach allowed for the aggregation of data to understand attendance barriers without creating long-term data storage issues.
