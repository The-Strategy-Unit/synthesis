# GitHub Version Control for Data Pipelines

Using GitHub for data pipeline development offers significant benefits for tracking changes, including code and images. Version tags, such as 0.0.1 or 0.0.2, are utilised to mark meaningful increments in the model. This allows for comparison between different sets of commits and timestamps, facilitating a clear history of how the model evolved. This practice supports reproducibility and enables easy comparison of changes between versions, which is particularly useful when iterating on complex data models.
