# Semi-automated MAT reporting workflow

A semi-automated data pipeline developed by NHS Lothian supports the reporting of Scotland's Medication Assisted Treatment (MAT) standards. This workflow replaces manual spreadsheet handling with a connected system that uses REDCap for secure data entry, R for data extraction and cleaning, Posit Connect for scheduled automation, and Flexdashboard with Plotly for visualization. The process is termed 'semi-automated' because it retains a manual step for quality assurance. This allows human judgment to verify data accuracy, handle service name changes, and select specific modular reports before final generation.

The primary aim of this approach is to improve accessibility for frontline staff, reduce version control issues, and provide weekly insights into local performance against national benchmarks. Key performance indicators include starting prescriptions within three days of a request. By moving away from emailed spreadsheets, the system enhances data governance through a secure, auditable environment. It reduces manual errors associated with reconciling file formats and merging data, while presenting key indicators through interactive charts rather than rows of raw data. This helps non-technical users explore data, spot pressure points, and shortlist key indicators from over 50 variables.
